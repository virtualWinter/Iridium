# Manifest coverage

Generated by `tools/webext/coverage.py`; see `compatibility.yaml` for the statuses.

`manifest_version` is 2 or 3. Keys are marked MV2-only, MV3-only or both by the
specification; a key that Iridium parses without acting on it is `partial`, because
parsing is not implementing.

in `permissions`, in `optional_permissions`, or in neither.
