# API coverage

Generated by `tools/webext/coverage.py` from `compatibility.yaml` (Iridium's status) and `data/api-inventory.json`
(the MDN and Gecko surface). Do not edit this file; edit the database.

## How to read this

A namespace is `full` only when its documented members, events, permissions,
errors and edge cases are implemented *and* covered by the named tests. A JS namespace
existing is not evidence of that. `partial` names what is missing in `compatibility.yaml`;
the member tables below list every documented member, so a missing one is visible next
to the implemented ones.

The Firefox and Chrome columns are upstream support data from MDN's browser-compat-data,
kept so a divergence from Firefox has to be a decision rather than an accident. `*` marks
a partial upstream implementation. A `-` in the Chrome column for a Firefox-only API is
expected and is not a gap for Iridium.

The specification surface is **69 namespaces** and **796 members**
(386 methods, 115 events, 73 properties, 222 types).
5 of them are at least partially implemented in Iridium today.
